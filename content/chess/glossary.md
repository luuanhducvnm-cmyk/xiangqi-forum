Chess has its own vocabulary. Here are the terms you will meet most often, in alphabetical order.

| Term | Meaning |
|---|---|
| **Algebraic notation** | The standard way to write moves, such as `Nf3`. See [notation](/chess/notation/). |
| **Back rank** | The first rank (White) or eighth rank (Black), where the pieces start. |
| **Bishop pair** | Having both bishops, which together cover all squares. |
| **Blunder** | A serious mistake that loses material or the game. |
| **Castling** | A king and rook move together; see [special moves](/chess/special-moves/). |
| **Center** | The four squares d4, d5, e4 and e5. |
| **Check** | The king is under attack. |
| **Checkmate** | The king is in check and cannot escape; the game ends. |
| **Decoy** | Luring a piece to a bad square. |
| **Deflection** | Forcing a defender away from its duty. |
| **Develop** | Move pieces from their starting squares to active positions. |
| **Discovered attack** | Moving a piece to reveal an attack from another piece. |
| **Double check** | Two pieces give check at once; only a king move helps. |
| **Draw** | A game that ends without a winner. |
| **ELO** | A rating system for player strength; see [ELO ratings](/elo-rating-explained/). |
| **En passant** | A special pawn capture. |
| **Endgame** | The final phase, with few pieces. |
| **Exchange** | Trading pieces; "winning the exchange" means winning a rook for a minor piece. |
| **FEN** | Text notation for a single position. |
| **Fianchetto** | Developing a bishop on b2/g2 (or b7/g7) after a pawn move to b3/g3 (or b6/g6). |
| **File** | A column of the board (a–h). |
| **Fork** | One move attacking two or more pieces. |
| **Gambit** | An opening sacrifice of a pawn for activity. |
| **Hanging piece** | An unprotected piece that can be captured. |
| **Increment** | Extra time added to your clock after each move. |
| **Initiative** | The ability to make threats that the opponent must answer. |
| **Isolated pawn** | A pawn with no friendly pawns on neighbouring files. |
| **Luft** | An escape square for the king (German "air"). |
| **Majority** | More pawns than the opponent on one wing. |
| **Material** | The pieces and pawns on the board. |
| **Middlegame** | The phase after the opening and before the endgame. |
| **Minor piece** | A bishop or knight. |
| **Major piece** | A rook or queen. |
| **Opposition** | Kings facing each other with one square in between. |
| **Open file** | A file with no pawns. |
| **Passed pawn** | A pawn with no enemy pawns in front on its file or adjacent files. |
| **Perpetual check** | Giving check every move to force a draw. |
| **PGN** | Portable Game Notation, a file format for games. |
| **Pin** | A piece cannot move without exposing a more valuable one. |
| **Promotion** | A pawn reaching the last rank becomes another piece. |
| **Rank** | A row of the board (1–8). |
| **Resign** | To concede the game. |
| **Sacrifice** | Giving up material for an advantage. |
| **Skewer** | An attack on a valuable piece that must move, exposing a lesser one behind it. |
| **Stalemate** | The player to move has no legal move and is not in check — a draw. |
| **Tempo** | A unit of time; one move. "Gaining a tempo" means making progress with a threat. |
| **Touch-move** | A touched piece must be moved (over-the-board rule). |
| **Transposition** | Reaching the same position by a different move order. |
| **Underpromotion** | Promoting to something other than a queen. |
| **Zugzwang** | Any move worsens the position. |
| **Zwischenzug** | An in-between move before the expected reply. |
